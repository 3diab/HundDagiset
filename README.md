# Hunddagiset

Startprojekt för **komplettering av Examinationsuppgift 1** i C#-kursen för Spelutvecklare på Nackademin.

Repositoryt innehåller materialet som behövs för examinationsuppgiften:

- `Hunddagiset.zip` - projektet som ska användas i uppgiften
- `Examinationsuppgift_1_Hunddagiset.pdf` - instruktioner och krav för examinationen

## Kom igång

1. Ladda ner eller klona repositoryt.
2. Läs igenom `Examinationsuppgift_1_Hunddagiset.pdf`.
3. Packa upp `Hunddagiset.zip`.
4. Öppna projektet i Visual Studio eller Rider.
5. Följ instruktionerna i examinationsuppgiften.

## Viktigt

Arbeta i en **egen kopia** av projektet.

Gör dina ändringar lokalt och följ instruktionerna för inlämning i studentportalen.

Ändra inte filerna i detta repository.

## Om systemet

Hunddagiset är en C#-konsolapp som hanterar incheckade hundar och tillgänglig kapacitet. En liten hund tar 0,5 plats, en medelstor hund tar 1 plats och en stor hund tar 1,5 platser. Systemet hanterar maxkapacitet, inte tidsbokningar.

## Syfte

Projektet används för att examinera felsökning, felhantering och grundläggande C#-programmering.
